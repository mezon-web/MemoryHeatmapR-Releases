# MemoryHeatmapR v1.3.1

- ヒートマップの背景色を従来の配色に戻しました。最新の実測増減から色と濃さを決め、平滑化は行いません。
- 最大化したときに下部のステータス欄がタスクバーに隠れる問題を修正しました。ウィンドウがあるモニターの作業領域に合わせて最大化します。

Windows 11 x64 / .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。旧版を閉じ、ZIP 内の `MemoryHeatmapR.exe` を起動してください。

- `MemoryHeatmapR-v1.3.1.zip` — アプリと日本語 HTML 説明書
- `MemoryHeatmapR-v1.3.1.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmapR-v1.3.1-manual.html` — 画像付きの単一 HTML 説明書
