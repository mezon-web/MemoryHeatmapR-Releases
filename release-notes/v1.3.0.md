# MemoryHeatmapR v1.3.0

- 四角・アプリ一覧・PID 行のダブルクリックから「メモリを整理」の確認画面を開けるようになりました。整理は確認画面の実行ボタンで開始します。
- アプリ一覧をアプリ名・専用 RAM・増減でソートでき、見出しの再クリックで昇順／降順を切り替えられます。
- 更新間隔を0.5・1・2・5・10秒から選べます。空き領域表示・更新間隔・ソート条件を EXE 横の設定ファイルに保存します。
- 背景色は半減期5秒でならした最近の増減傾向を表示し、短い揺れによる点滅を抑えます。使用量・増減の数値、面積、ソートは実測値です。
- 空き領域の凡例をほかの色と同じ行へ移し、更新時の配置計算・描画・メモリ確保を軽量化しました。

Windows 11 x64 / .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。旧版を閉じ、ZIP 内の `MemoryHeatmapR.exe` を起動してください。

- `MemoryHeatmapR-v1.3.0.zip` — アプリと日本語 HTML 説明書
- `MemoryHeatmapR-v1.3.0.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmapR-v1.3.0-manual.html` — 画像付きの単一 HTML 説明書
