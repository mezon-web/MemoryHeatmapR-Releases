# MemoryHeatmapR v1.2.8

タイトルバーの最大化ボタンをクリックできない問題と、灰色のボタンが重なって表示される問題を修正しました。マウス操作後にフォーカス枠が残らないようにし、キーボード操作時の枠は残しています。

Windows 11 x64 / .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。旧版を閉じ、ZIP 内の `MemoryHeatmapR.exe` を起動してください。

- `MemoryHeatmapR-v1.2.8.zip` — アプリと日本語 HTML 説明書
- `MemoryHeatmapR-v1.2.8.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmapR-v1.2.8-manual.html` — 画像付きの単一 HTML 説明書
