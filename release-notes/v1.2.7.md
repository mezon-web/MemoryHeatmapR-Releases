# MemoryHeatmapR v1.2.7

旧版の `MemoryHeatmap.settings.json` が新しい EXE と同じ場所にある場合は、初回起動時に表示設定を `MemoryHeatmapR.settings.json` へ引き継ぎます。旧ファイルはバックアップとして残します。

Windows 11 x64 / .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。旧版を閉じて、新しい ZIP の `MemoryHeatmapR-v1.2.7` フォルダ内にある `MemoryHeatmapR.exe` を起動してください。

- `MemoryHeatmapR-v1.2.7.zip` — アプリと日本語 HTML 説明書
- `MemoryHeatmapR-v1.2.7.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmapR-v1.2.7-manual.html` — 画像付きの単一 HTML 説明書

v1.2.6 以前の配布物は、当時の名前と内容のまま履歴として残しています。
