# MemoryHeatmap v1.2.6

上部のアプリヘッダーとウィンドウのタイトルバーを1段に統合しました。アプリアイコン、計測状態、版表示を同じ段にまとめ、右端に最小化・最大化／元に戻す・閉じるボタンを配置しています。

タイトルバーの空いた場所でウィンドウを移動でき、ダブルクリックで最大化／元に戻すを切り替えられます。ウィンドウ端のサイズ変更や、右クリックのシステムメニューも利用できます。

Windows 11 x64 / .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。
旧版を閉じて、新しい ZIP の `MemoryHeatmap-v1.2.6` フォルダ内にある MemoryHeatmap.exe を起動してください。
表示設定を引き継ぐ場合は、EXE の隣の MemoryHeatmap.settings.json を残してください。

- `MemoryHeatmap-v1.2.6.zip` — アプリと日本語 HTML 説明書
- `MemoryHeatmap-v1.2.6.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmap-v1.2.6-manual.html` — 画像付きの単一 HTML 説明書
