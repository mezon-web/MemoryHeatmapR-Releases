Windows 11 x64 · v1.3.0

MemoryHeatmapR 使い方

四角の大きさと色で、メモリを使っているアプリや最近の増減を確認できます。

.NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。未導入の場合は Microsoft の配布ページで「.NET Desktop Runtime」の Windows x64 を選んでください。

基本の使い方主な操作右クリック操作困ったとき補足

まずはこの3ステップ

  1. 起動する：ZIP を展開し、MemoryHeatmapR.exe をダブルクリックします。インストール・管理者権限は不要です。
  2. マップを見る：大きい四角ほど、アプリ専用の RAM を多く使っています。背景色の赤は増加傾向、緑は減少傾向です。増減は起動から約10秒で表示され、初期設定では2秒ごとに更新します。
  3. アプリを調べる：気になる四角をクリックすると、右側に所属プロセスの PID・使用量・増減が出ます。「検索」でアプリ名・PID・パスを絞り込めます。
赤：増加緑：減少暗色：変化小・計測中

面積は表示中のアプリ同士の専用 RAM の比率です。OS・共有メモリを含む、上部の PC 全体の使用量とは別の集計です。小さい四角はマウスを重ねると詳細が読めます。

主な操作

検索・クリアアプリ名・PID・実行ファイルのパスで絞り込みます。「クリア」で全アプリに戻します。検索中はアプリの面積比を計算し直します。
更新間隔上部の「更新」で0.5・1・2・5・10秒を選べます。変更すると増減を再計測します。一時停止中に変更しても停止したままです。
アプリ一覧のソート「アプリ」「専用 RAM」「増減」の見出しで並べ替えます。同じ見出しを押すと昇順・降順を切り替えます。選択した順序は計測更新後も保ちます。
一時停止・再開新しい計測を止めます。停止中も検索・選択・空き領域の切り替えができます。再開後、増減の表示には約10秒かかります。
空き領域を表示検索の左のチェックボックスで、左端に青灰色の「利用可能 (空き)」を追加します。幅は PC 全体の利用可能量の割合で、再利用できるスタンバイメモリも含みます。右側のアプリは、その中での相対比で表示します。空きの幅は検索で変わりません。
ウィンドウ上部のタイトルバーで移動し、右端のボタンで最小化・最大化／元に戻す・閉じる操作ができます。タイトルバーの空いた場所をダブルクリックすると最大化／元に戻すを切り替えます。

ダブルクリックで整理・右クリックで操作する

四角・右側のアプリ一覧・PID 行をダブルクリックすると「メモリを整理」の確認画面が開きます。整理は画面内の実行ボタンで開始します。右クリックからは整理・タスク終了・ファイルの場所を開く操作を選べます。

  • メモリを整理…：RAM に常駐する量を減らします。確保済みのコミット量は残ります。再び使うと RAM 使用量が戻ったり、一時的に遅くなったりします。CPU 使用中や前面の対象はスキップします。
  • タスクを終了…：選択した PID を強制終了します。未保存のデータが失われる可能性があります。
  • ファイルの場所を開く：実行ファイルをエクスプローラーで選択表示します。

整理・終了の確認画面で、対象の PID にチェックを付けてから実行します。「全選択」は操作可能な行をまとめて選び、「解除」はチェックを外します。操作しない場合は「閉じる」で戻れます。

四角・アプリ一覧から開いた確認画面は未選択です。PID 行からはその1件が選択済みです。確認後に増えたプロセスや子プロセスを自動で対象へ追加しません。実行中の「中止」は次の処理を止めますが、実行済みの操作は取り消せません。

システムの重要な処理・別ユーザーのプロセス・MemoryHeatmapR 自身などは操作できません。操作しなかった理由は確認画面に表示します。自動整理は行いません。

困ったとき

起動できない
ZIP を展開した EXE を使ってください。Windows 11 x64 と .NET 10 Desktop Runtime x64 が必要です。通常の .NET Runtime だけでは起動できません。Windows 11 22H2 の2023年9月更新以降が対象です。
「計測中」のまま・色が付かない
起動・再開・更新間隔変更・スリープ復帰後や、新しく起動したアプリは約10秒待ってください。背景色は最近の増減傾向を示し、短い揺れでは色が変わりにくくなっています。数値は最新の実測値です。
「取得不可」「一部取得不可」「*」が出る
保護されたプロセスなどは通常権限で情報を取得できません。取得失敗を0として扱わず、「*」は取得できた分だけの合計を示します。一部取得不可の間は増減比較を保留します。起動時刻を確認できない場合は「比較不可」です。
アプリが見つからない・四角がない
「クリア」で検索を解除し、右下のアプリ一覧を確認してください。取得不可や使用量0のアプリも一覧から選べます。終了したプロセスは次の更新で消えます。
整理・終了できない
確認画面の状態・結果欄を確認してください。保護対象・権限不足・確認後に終了や再起動をした対象などはスキップします。

補足

空き領域の見方・設定の保存

「利用可能 (空き)」は上部の AVAILABLE と同じ値です。総容量32 GiB 中16 GiB が利用可能なら、左半分が空きになります。右半分には表示中のアプリを専用 RAM 比で配置します。マップ全体が PC の使用量の内訳を表すものではありません。

検索で1件に絞ると、そのアプリが右側を占めます。検索結果がなければ右側は空白です。空きは表示専用で、クリックや右クリックの対象にはなりません。

初回は OFF です。空き領域の選択・更新間隔・アプリ一覧のソート条件は EXE の隣の MemoryHeatmapR.settings.json に保存し、次回起動で復元します。旧版の MemoryHeatmap.settings.json が同じ場所にあり、新しい設定ファイルがまだない場合は初回起動時に内容を引き継ぎます。旧ファイルはバックアップとして残します。

初期設定は空き領域 OFF・更新2秒・専用 RAM 降順です。設定ファイルがない・読み込めない場合や、旧設定に項目がない場合は初期値を使います。選択が保存されないときは、EXE のフォルダーに書き込みできるか確認してください。その場の切り替えは引き続き使えます。

専用 RAM・コミット量・増減の意味

専用 RAMは、現在 RAM にあり、そのプロセス専用となっているメモリ（プライベートワーキングセット）です。同じ実行ファイルのフルパスのプロセスを合算します。別の場所にある同名アプリは別表示です。

コミット量は、ページファイルへ退避した分も含む確保済みメモリです。RAM 使用量とは異なります。アプリを選ぶと右側に表示し、PID 行にマウスを重ねるとプロセスごとの値も読めます。

増減は10秒以上前の直近の計測値との差で、アプリの起動・終了の影響も含みます。緑色の減少には手動整理の影響も含まれます。手動操作の印は約2分表示し、アプリ終了時に消えます。

背景色は符号付きの増減を半減期5秒でならした「最近の増減傾向」です。±1 MiBで色が付き、0.5 MiB未満になるまで暗色へ戻さず、短い揺れによる点滅を抑えます。小さい傾向は淡く、大きい傾向は濃く表示します。使用量・増減の数値、面積、ソートは実測値を使います。マウスを重ねると実際の比較時間も確認できます。

マップは初回は使用量順、その後は既存の並びを保ちます。使用量によって四角の境界は動きます。単位は MiB（1,048,576 バイト）・GiB（1,073,741,824 バイト）です。タスクマネージャーとは集約方法・更新時刻・列の定義が異なるため、数値が一致しない場合があります。

キーボードで操作する
  • Ctrl + F：検索欄へ移動。検索欄で Esc：検索を解除。
  • Ctrl + Space：一時停止／再開。
  • マップにフォーカスがあるとき、矢印・Home・End：アプリを選択。
  • Shift + F10 またはメニューキー：対象の右クリックメニューを開く。
